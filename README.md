# Selenium Java TestNG POM Framework

## Tech Stack
- Java 17
- Selenium 4
- TestNG
- Maven

## Framework Structure
- DriverFactory: WebDriver management
- BaseTest: setup/teardown using TestNG
- Page Objects: locators + actions (POM)
- Tests: scenarios + assertions

## How to Run
- Run via IntelliJ: Right-click test class -> Run
- Run via Maven:
  mvn test
